# Dict_AI_Coding Generated Artifacts Map

## Goal

Distinguish important generated evidence from rebuildable cache output.

## Artifact Classes

- `protocol_evidence`: generated and kept because the workflow relies on it.
- `managed_projection`: generated by synchronization from another note.
- `derived_summary`: generated summary useful for navigation.
- `runtime_state`: local process/service state.
- `compiled_noise`: rebuildable bytecode and caches.

## Repo-Change Evidence

Pattern:

- `mcp/repo-change-guard/<session>/session.json`
- `mcp/repo-change-guard/<session>/task_snapshot.md`
- `mcp/repo-change-guard/<session>/closeout.md`
- `mcp/repo-change-guard/<session>/closeout.md.change-receipt.json`
- `mcp/repo-change-guard/<session>/change_receipt.json`
- `mcp/repo-change-guard/<session>/p7-e2e-proof/*`

Classification:

- `protocol_evidence`

Producer:

- `repo-change-guard`

Consumer:

- reviewers
- future handoff notes
- worktree cleanup audit

## Imported Change Sessions

Pattern:

- `change_sessions/<session>/session.json`
- `change_sessions/<session>/task_snapshot.md`
- `change_sessions/<session>/change_receipt.json`

Classification:

- `protocol_evidence`

These are small but important. Do not delete or hide them without a local
manifest policy.

These paths are now under the active `local_git_manifested` boundary.

## Review Sync Projections

Pattern:

- `reviews/<agent>/handoff/*.md` with `sync_managed_copy: true`
- `reviews/global_handoff/*.md` when produced from source-agent handoffs

Classification:

- `managed_projection`

Producer:

- `scripts/sync_reviews.py`
- `scripts/sync_reviews_watch.py`

Important behavior:

- source notes are never overwritten by sync
- filename collisions with different digest create explicit variant files
- managed copies carry source path and digest frontmatter

## Review Summaries And Catalog

Files:

- `knowledge/80_summaries/team_review_latest.md`
- `knowledge/80_summaries/team_review_digest.md`
- `knowledge/80_summaries/team_review_changelog.md`
- `mcp/catalog.json`

Classification:

- `derived_summary`

Producer:

- `scripts/sync_reviews.py`

Consumer:

- agents and humans navigating the review state
- MCP-style catalog consumers

These files are generated, but not worthless. They should either be committed as
navigation artifacts or represented by a local manifest policy.

`knowledge/80_summaries/` and `mcp/catalog.json` are now represented by the
active local-git manifests rather than pushed as raw payload.

## Local Git Manifests

Files:

- `ops/local_git_manifests/change_sessions.json`
- `ops/local_git_manifests/review_sessions.json`
- `ops/local_git_manifests/knowledge_summaries.json`
- `ops/local_git_manifests/mcp.json`
- `ops/local_git_manifests/pushable_tracked.json`
- `ops/local_git_manifests/index.json`

Classification:

- `protocol_evidence`

Producer:

- `scripts/local_git_guard.py`

Consumer:

- pre-commit and pre-push hooks
- future cleanup and audit work
- human review of local-only boundary drift

## Service And Sync Runtime

Repo-local source:

- `systemd/dict-ai-coding-review-sync-watch.service`
- `install-review-sync-user-service.sh`

Runtime outside repo:

- installed user service in `~/.config/systemd/user/`
- systemd logs
- running watcher process

Classification:

- repo-local files: `canonical_source`
- installed service and logs: `runtime_state`

## Compiled Noise

Patterns:

- `**/__pycache__/`
- `*.pyc`
- `.pytest_cache/`
- `node_modules/`
- `dist/`
- `build/`

Classification:

- `compiled_noise`

Current observed cache dirs:

- `scripts/__pycache__/`
- `skill/tests/__pycache__/`
- `skill/tests/e2e/__pycache__/`
- `skill/tests/fixtures/planted-bugs/__pycache__/`

These should not be deleted by default. After freeze, they can either stay
ignored as rebuildable local cache or be moved to a manifest-backed archive.

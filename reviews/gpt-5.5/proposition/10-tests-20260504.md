# Garanties testees

- `A_atomic_write` reconnait le direct write `path.write_text(json.dumps(...))` et documente le fix `tmp.replace(path)`.
- `B_cascade_failure` cible le couple `subprocess.run` non gere + `return 0`.
- `C_scan_loop_safe` couvre un `yaml.safe_load` dans boucle de scan et le vocabulaire `skip+report`.
- `J_bidir_test_coverage` detecte le risque d'un test `upper` sans branche `lower`.
- `E_llm_hallucination` detecte une citation `catalog.py:358` non lue dans la session.
- `validate.ts` accepte le projet courant, rejette un check sans frontmatter, et rejette un trigger qui appelle un check inexistant.

# Changement associe

`scripts/skill-lib.ts` accepte `SKILL_PROJECT_ROOT` pour permettre aux tests de copier `skill/` dans un repertoire temporaire et tester les erreurs du validator sans polluer le workspace.

# Limites

Ces tests prouvent les artefacts Markdown et la validation structurelle. Ils ne remplacent pas le smoke test dynamique P7, qui devra prouver qu'un LLM applique un preflight pendant une tache de coding.

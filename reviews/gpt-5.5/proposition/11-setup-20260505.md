# Discipline de securite

- Installation par symlink vers le dossier source `skill/`.
- `setup` refuse une cible existante si elle n'est pas deja un lien gere vers ce repo.
- `uninstall` ne supprime que les symlinks pointant vers ce repo.
- `--dry-run` permet de voir les actions sans ecriture.
- Validation avant installation : `gen:skill-docs` puis `validate`.
- Si Bun n'est pas sur le PATH, le script utilise l'env Conda `coding-best-practices`.

# Commandes utilisateur

```bash
bash skill/setup --host all --yes
bash skill/uninstall --host all --yes
```

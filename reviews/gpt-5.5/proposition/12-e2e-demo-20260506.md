# P7 - E2E demo

## Summary

P7 adds a deterministic E2E harness that installs the skill into a temporary
Claude/Codex home, loads the installed symlinked artifact, audits planted-bug
fixtures, and writes structured proof to `result.json`.

The Phase 1 backend is `mock` by design. It proves trigger/check routing and
installed artifact shape without spending API calls or depending on real Claude
Code behavior.

- `skill/tests/e2e/run.sh`
- `skill/tests/e2e/mock_agent.py`
- `skill/tests/test_e2e_harness.py`

## Checks Proven

- `A_atomic_write` fires on direct `write_text(json.dumps(...))`
- `B_cascade_failure` fires on unchecked `subprocess.run` followed by `return 0`
- `C_scan_loop_safe` fires on `yaml.safe_load` inside a batch scan without
  per-item handling
- `J_bidir_test_coverage` is also emitted for the planted one-sided test fixture
- Clean atomic-write control emits zero findings
